# MEMO — {ROLE} — {timestamp}

> **This file is CLI-generated by `sigma memo write`. Do not create or rename memo files manually.**
> File location: `Sigma/messages/{ROLE}/MEMO-{ROLE}-{timestamp}-{suffix}.md`
> A memo is always self-addressed (`from === to`) — it is not a cross-role message. Use `sigma send` for that.
> Not a substitute for any Sigma governance artifact — see PLAN-IMPL-SIGMA-MEMO-OPERATIONAL-BRIEF-20260902 §2 (key principle) and §7 (memo vs. the removed CHECKPOINT/CSO feature).

The three metadata lines below the header (Chain / Phase / Version, Sigma Artifact Reference, Topic) are generated by the CLI from the active chain and from `--ref` / `--topic` — never write them by hand. Everything from "Context" down is written by the caller (normally the `/write-memo` skill).

```
## Memo — <ROLE> — <YYYY-MM-DD HH:MM>

**Chain / Phase / Version:** <chain-vN> | <DESIGN|BUILD|CLOSE|CLOSED> | INTENT <vN> (<STATE>) · PLAN <vN> (<STATE>) · EXEC <vN> (<STATE>)

**Sigma Artifact Reference:** <INTENT-vN|PLAN-vN|EXEC-vN|GENERAL>

**Topic:** <one sentence>

**Context (only what isn't already in the artifact):**
<2-3 sentences — direction of this session's discussion, why it stopped here. Not a summary of artifact content.>

**Reorientation — Read:**
- <artifact ref + section, e.g. exec-evidence §1.2>
- <inbox msg ref, e.g. inbox msg abc123 from FMN>

**Next Actions:**
- <concrete operational instruction>
- avoid: <a path already tried and failed, with a short reason>

**Blocked — Do Not Proceed Until:**
- <a Director decision on X, or role Y's reply to msg Z>
```

Section rules:

- **Context** and **Blocked** may be empty — write `—`.
- **Reorientation — Read** and **Next Actions** must have content — that is the point of a memo.
- A memo carries pointers, not artifact snapshots. If a substantive conclusion hasn't been formalized into a real Sigma artifact yet, it may appear here only paired with a formalization instruction: `Conclusion: <X>. → formalize into exec-evidence §1.2 before proceeding.` A decision must not live only in a memo across more than one session hop.
- If something genuinely needs a detailed explanation, do not write that detail here — create a new `.md` file under `Sigma/notes/` (no Director approval needed for that) and point to it from "Reorientation — Read" instead. See the `/write-memo` skill's "Keeping Memos Brief" section.
