# Reference List

> Project-wide source index for Comprehensive Research (DIR-INTENT Section 2).
> Not a formal bibliography — a path/link and a short note is enough for any
> Sigma role to revisit the source later.
>
> Cite sources in DIR-INTENT by ID only — e.g. "(LA02)" or "(WL01, WL03)" —
> not by re-explaining where to look. IDs are prefixed by table (LA = Local
> Artifact, WL = Website Link, OS = Online Source Data) followed by a
> sequential two-digit number (LA01, LA02, ...). IDs are assigned once and
> never reused or renumbered, even if a row is later found stale.

> containing `2021.csv`, `2022.csv`, ...) is recorded as one row for the
> folder, not one row per file nested inside it.
